# 🎓 Student Registration & Result Portal

## 📖 Overview
The Student Registration & Result Portal is a responsive web-based mini project built using **HTML5** and **CSS3**. It allows students to register their details, select courses, enter marks, and view results in a structured and visually appealing layout.

## 🚀 Features
- Student Registration Form with validation
- Course selection dropdown
- Marks entry for multiple subjects
- Results display in a styled table
- Responsive design using CSS3
- Clean and polished UI with form styling

## 🛠 Tech Stack
- HTML5
- CSS3
