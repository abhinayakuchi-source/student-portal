# 🎓 Student Portal

A modern and responsive **Student Portal** designed using **HTML5, CSS3, and Bootstrap 5**. The project provides a clean and organized interface for a student-focused web portal while applying essential frontend development concepts.

---

## 📌 Project Overview

The **Student Portal** is a frontend web development project created to practice and demonstrate fundamental web design and responsive UI development concepts.

The project focuses on building a structured, attractive, and user-friendly interface using:

- HTML5
- CSS3
- Bootstrap 5

---

## 🎯 Objectives

- Create a professional student portal interface.
- Practice semantic HTML5 structure.
- Apply CSS3 styling techniques.
- Use Flexbox and CSS Grid for layouts.
- Build responsive webpages.
- Use Bootstrap 5 components and utilities.
- Create a clean and user-friendly student interface.
